# JMR's Gauntlet

Browser-playable Gauntlet projects by Jonathan M. Rothberg (JMR).

## Play online

- **[JMR's Original](https://jmrothberg.github.io/Gauntlet/JMR-original/)** — original Atari Lynx *Gauntlet: The Third Encounter*, hosted for direct browser play on iPad, iPhone, and desktop.
- **[Gauntlet: Best Of](https://jmrothberg.github.io/Gauntlet/Gauntlet_bestof.html)** — browser recreation with mobile controls.
- **[Gauntlet (single-file)](https://jmrothberg.github.io/Gauntlet/Gauntlet_1FILE_Oct_29_25.html)** — illustrative-sprite browser build.

## JMR's Original

`JMR-original/` contains the mobile-first browser launcher for the original Lynx game. It uses the Lynx emulator core through EmulatorJS and loads the hosted game image directly, so the player does not need to select a ROM file.
