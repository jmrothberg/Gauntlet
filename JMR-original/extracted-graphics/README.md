# Extracted graphics

This directory is reserved for verified graphics captured or decoded from the original 131,136-byte cartridge.

Atari Lynx artwork is rendered through Suzy sprite command blocks and may be packed, scaled, flipped, reused, or assembled dynamically. Arbitrary fixed-size chunks of cartridge bytes are therefore **not** presented as sprites. PNG sheets placed here must state whether they came from decoded Suzy data or from lossless captures of the Handy-emulated Lynx framebuffer.
